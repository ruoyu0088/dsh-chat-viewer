# Third-party static assets

The viewer ships local, offline copies of the following browser libraries.
They are unmodified copies taken from the Hermes Chat Viewer project:

| Asset | Project | License |
|---|---|---|
| `static/marked.min.js` | [marked](https://github.com/markedjs/marked) | MIT |
| `static/katex/` (JS, CSS, fonts) | [KaTeX](https://katex.org/) | MIT |
| `static/hljs.min.js`, `static/hljs-*.css` | [highlight.js](https://highlightjs.org/) | BSD-3-Clause |
| `static/hljs-powershell.js` | highlight.js PowerShell grammar | BSD-3-Clause |
| `static/hljs-dos.js` | highlight.js DOS/CMD grammar | BSD-3-Clause |

The Python code in this project uses only the Python standard library.
